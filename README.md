# Éclats Éternels

Jeu mobile HTML5 « clicker » (tactile, installable en PWA) : tape le cristal, achète des améliorations, personnalise ton cristal et ton décor dans la boutique, puis renais pour gagner des bonus d'éternité. L'ancien jeu d'attrape est dans `catcher.html`.

Lancer : `python3 -m http.server` puis ouvrir `http://localhost:8000` sur mobile (ou héberger sur GitHub Pages).
Contrôles : glisser (tactile/souris) ou flèches ←/→.
